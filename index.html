Capabilities
Feature Arsenal
⊕

3D Pull Markers

Numbered ground circles placed at each pull's centroid using world-to-screen projection. Color-coded by pull index with pulsing active-pull highlight and distance labels.

⬡

Convex Hull Groups

Automatic convex hull computation around mob groups with padded fill and glow borders. Visually clusters each pull into a cohesive shape on the ground plane.

◈

Navigation Beam

Animated chevron beam from the player to the next pull center with distance readout. Pulses at the destination and fades based on progress along the path.

◆

Bloodlust Markers

Floating diamond-shaped 3D markers on lust pulls with pulsing glow animation and a vertical beam tether. Mark up to two lust pulls via the settings GUI.

⊘

Skip Detection

Mobs in the dungeon markings but not assigned to any pull are rendered with gray X markers, making it clear which mobs should be avoided on the route.

⟁

Entity System

Auto-discovers the WoW object manager and reads live entity positions. Matches route mobs to live creatures by NPC ID and proximity for real-time tracking.

▣

Tron Settings GUI

In-game draggable panel with animated circuit borders, glowing toggles, sliders, and tabbed navigation. Three tabs: Visuals, Markers, and Route info.

◈

MDT Route Import

Reads route data from the MDT addon's SavedVariables plus custom OverwatchBridge markings files. Maps every enemy clone to a pull number for precise placement.

⊡

Death Tracking

Detects when matched entities disappear from the object manager and marks their route clones as dead. Past pulls auto-dim as you clear through the dungeon.
